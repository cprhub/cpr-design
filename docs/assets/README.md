# Logo & favicon

Læg de officielle Coding Pirates-logofiler her, hentet fra designguiden:
https://codingpirates.dk/designguide/

Filnavne som mkdocs.yml forventer:
- `logo.png` — vises i topmenuen (brug "Coding Pirates Skrift Logo", web-version, PNG)
- `favicon.png` — browserfanens ikon (32×32 eller 64×64 px udsnit af logoet)

Husk designguidens regel om luftrum omkring logoet, og brug ikke maskotterne
(Kaptajn Hack / Miss Lead) alene uden et primærlogo ved siden af.
