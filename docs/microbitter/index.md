# MICROBITTER

Microbitter programmerer **micro:bit** — en lille computer med lys, knapper og sensorer, som man kan få til næsten hvad som helst.

Microbitternes eget materiale ligger på et separat site, som holdets leder står for:

**[Gå til Microbitternes materiale (cpr-microbit)](https://itsgauravsaxena.github.io/cpr-microbit/)**
